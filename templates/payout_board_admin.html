⚙ What's Automated vs What You Must Do
✅ Handled Automatically
  • Player Code generation
  • Public alias generation
  • Submission confirmation email
  • Tier eligibility calculation from views
  • Spot release when player goes Overtime
  • Bonus Bank: +$100 on mini-game win, $0 on loss
  • Duplicate bonus prevention per overtime round
  • Verification email when you click Verify
  • Cashout-received email when player submits
  • Live board dot/spot updates (every 30s)
  • Private data protected on public board
  • Player can return with Player Code anytime
👤 Admin Must Do Manually
  • Review screenshot when player reaches cashout
  • Click Verify to confirm view count is real
  • Click Approve Cashout after BP submits form
  • Click Mark Paid after sending payment in the payout provider
  • DQ suspicious or fraudulent players
  • Export CSV for the payout provider payment processing
  • Adjust tier caps if needed
  • Open / close wildcard window
  • Monitor Fraud Radar for suspicious activity
  • Handle support if a player loses their code
⚡ Players do not wait for admin review before accessing the game. They can submit, play, and make their Cash Out / Go Overtime decision independently. Admin reviews screenshots during the cashout verification step only.
